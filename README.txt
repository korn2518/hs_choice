고교 선택 길잡이 - 배포 안내
두레자연중학교 진학 안내, 2027학년도 입학 기준
================================================================

[들어 있는 파일]
- index.html             학생이 여는 앱 (이 파일 하나만 인터넷에 올리면 됩니다)
- apps_script_code.txt   구글 시트에 붙여 넣는 취합 코드 (인터넷에 올리지 않습니다)
- README.txt             이 안내문


[학생이 하는 일]
1. 학급 번호, 이름, 전화번호를 적고 거주 지역(시·도, 시·군·구)을 고릅니다.
   세 칸을 모두 적어야 다음 화면으로 넘어갑니다.
2. 거주지역 고등학교(1~5순위)나 전국단위 모집 학교(유형마다 2곳)를 고릅니다.
3. 전형 안내 화면 맨 아래에서 내 정보를 확인하고, 제출 동의에 표시한 뒤
   [선생님께 제출]을 누릅니다.


[배포 순서]

※ 이전 판을 이미 배포해 쓰고 있다면 (웹 앱 주소를 그대로 쓰는 방법)
  1) 쓰던 시트의 확장 프로그램 > Apps Script 를 열어 코드를 모두 지우고
     apps_script_code.txt 내용으로 바꾼 뒤 저장합니다.
  2) [배포] > [배포 관리] > 연필 아이콘 > 버전: 새 버전 > [배포]
     ([새 배포]로 하면 주소가 새로 생깁니다. [배포 관리]로 해야 주소가 그대로입니다.)
  3) index.html 의 GAS_URL 따옴표 안에 예전에 쓰던 주소를 그대로 넣습니다. (2단계 참고)
  4) GitHub 저장소의 index.html 을 새 파일로 바꿔 올립니다. 그다음 4단계(시험 제출)로.
  아래 1단계는 처음 설치할 때만 필요합니다.

1단계. 구글 시트 준비 (처음 설치할 때)
  1) 구글 드라이브에서 새 스프레드시트를 만듭니다. (예: 2027 고교 선택 조사)
  2) 메뉴에서 확장 프로그램 > Apps Script 를 엽니다.
  3) 보이는 코드를 모두 지우고 apps_script_code.txt 내용 전체를 붙여 넣고 저장합니다.
  4) 위쪽 함수 목록에서 setup 을 고르고 [실행]. 권한 요청이 나오면 허용합니다.
     시트에 "응답", "기록", "학교별집계" 탭이 생기면 성공입니다.
  5) [배포] > [새 배포] > 유형: 웹 앱
       다음 사용자 인증 정보로 실행: 나
       액세스 권한이 있는 사용자: 모든 사용자
     [배포]를 누르고 나오는 웹 앱 URL(.../exec 로 끝남)을 복사합니다.

2단계. index.html 에 주소 넣기
  1) index.html 을 메모장으로 엽니다. (마우스 오른쪽 > 연결 프로그램 > 메모장)
  2) 위에서 12번째 줄쯤에 있는
         const GAS_URL = "";
     의 따옴표 안에 복사한 주소를 붙여 넣습니다.
         const GAS_URL = "https://script.google.com/macros/s/..../exec";
  3) 저장합니다. (인코딩은 UTF-8 그대로)

3단계. GitHub Pages 에 올리기
  1) GitHub 에서 새 저장소(repository)를 만듭니다. (예: hs-guide, Public)
  2) [Add file] > [Upload files] 로 index.html 을 올리고 Commit 합니다.
  3) Settings > Pages > Source: Deploy from a branch, Branch: main / (root) > Save
  4) 1~2분 뒤 https://(내 계정).github.io/(저장소 이름)/ 주소로 열립니다.
     이 주소를 학생들에게 알려 주면 됩니다.

4단계. 시험 제출
  학생에게 알리기 전에 직접 한 번 제출해 보고, 구글 시트 "응답" 탭에
  한 줄이 생기는지 확인하세요. 시험으로 넣은 줄은 지우면 됩니다.


[구글 시트에 모이는 내용]
- 응답        학생 한 명당 한 줄.
              제출시각, 학급 번호, 이름, 전화번호, 거주 지역, 평준화 여부,
              거주 1~5순위, 전국단위 선택, 전기 학교 수, 후기 학교 수, 메모
              같은 학급 번호와 이름으로 다시 제출하면 그 줄을 덮어씁니다.
- 기록        제출할 때마다 한 줄씩 쌓이는 원본 기록.
- 학교별집계  학교별 1순위 수, 선택 수, 선택한 학생. 제출 때마다 다시 계산됩니다.


[개인정보]
- 학생이 적은 학급 번호, 이름, 전화번호, 메모는 제출 전까지 그 기기에만 있고
  브라우저 창을 닫으면 지워집니다. 고른 학교 목록만 기기에 남습니다.
- 여러 학생이 같은 컴퓨터를 이어서 쓸 때는 제출 뒤 [처음부터 다시]를 누르게 하세요.
- 제출된 내용은 선생님의 구글 시트에만 저장됩니다. 웹 앱 주소로는 자료를 넣을 수만
  있고 읽을 수는 없습니다. 시트 공유 설정은 꼭 필요한 사람으로만 해 두세요.
- 전화번호를 모으므로, 수집 목적(진학 상담)과 보관 기간을 학생과 보호자에게
  미리 알려 두는 것이 좋습니다.


[자주 생기는 문제]
- "아직 제출 주소가 연결되지 않았습니다"가 보인다
    index.html 의 GAS_URL 따옴표 안이 비어 있습니다. 2단계를 다시 확인하세요.
- 제출했는데 시트에 안 들어온다
    웹 앱 배포의 액세스 권한이 "모든 사용자"인지 확인하세요.
    웹 앱 주소를 브라우저 주소창에 넣었을 때 {"ok":true,...} 가 보이면 정상입니다.
- Apps Script 코드를 고쳤는데 반영이 안 된다
    [배포] > [배포 관리] > 연필 아이콘 > 버전: 새 버전 으로 다시 배포해야 합니다.
- 이전 판 코드를 쓰던 시트에 새 코드를 붙여 넣었다
    열 구성이 달라져서 예전 "응답", "기록" 탭은 첫 제출이 들어올 때 "응답_이전_날짜" 이름으로
    자동 보관되고 새 탭이 만들어집니다. 예전 자료는 지워지지 않습니다.


[이번 판에서 바뀐 것]
- 첫 화면에 학급 번호, 이름, 전화번호 입력 추가 (거주 지역과 함께 취합)
- 제출 화면에 내 정보 확인, 제출 동의 표시 추가
- 기숙사가 있는 일반계고에 삼괴고(화성시 우정읍), 병점고(화성시 병점동) 추가
- 김천고는 전국단위 자사고라 "자사고" 유형에 들어 있습니다.
  기숙형 일반계고 화면에 그 안내 문구를 넣었습니다.
