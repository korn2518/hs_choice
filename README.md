# 고교 선택 길잡이

두레자연중학교 진학 안내용 웹앱입니다. 거주지를 고르면 평준화 여부를 알려 주고,
거주지역 고등학교(1~5순위) 또는 전국단위 모집 학교를 골라 전기, 후기와 전형 안내를 봅니다.
고른 학교는 지도에 표시되고, 제출하면 구글 시트에 모입니다.

## 파일
- `index.html` : 앱 전체(학교 자료와 지도 포함). 이 파일 하나만 있으면 동작합니다.
- `apps_script_code.txt` : 구글 시트에 붙여 넣은 Apps Script 코드(보관용).
- `.nojekyll` : GitHub Pages 가 파일을 그대로 내보내게 하는 빈 파일.

## GitHub Pages 에 올리기
1. GitHub 에서 새 저장소를 만든다. (예: `hs-guide`)
2. 이 폴더의 파일을 모두 저장소에 올린다. (Add file > Upload files)
3. Settings > Pages > Branch 를 `main`, 폴더를 `/ (root)` 로 고르고 Save.
4. 1~2분 뒤 `https://<계정이름>.github.io/<저장소이름>/` 로 접속한다.

## 제출 주소 바꾸기
`index.html` 맨 위의 `const GAS_URL = "...";` 따옴표 안의 주소를 바꾸면 됩니다.
